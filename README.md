# DeptBoard — Attendance & Results Dashboard

React/Vite implementation of the **Project 14: DeptBoard — Attendance & Results Dashboard** case study.

## Included
- Dashboard with attendance distribution and subject averages
- Student table with search and sortable columns
- Low-attendance highlighting below 75%
- Student profile with editable attendance and marks
- Marks management screen
- Add-student form
- CSV import with required-column validation
- CSV export
- Responsive desktop/mobile layout
- No paid services or backend required

## Run in VS Code

Install Node.js (LTS), then open this folder in VS Code.

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, normally:
`http://localhost:5173`

For a production check:
```bash
npm run build
```
